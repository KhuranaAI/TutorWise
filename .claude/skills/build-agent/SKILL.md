Follow `_planner/agents/RECIPE.md` exactly, using the templates in `_planner/agents/templates/`.

- Work one agent and one stage at a time; never skip a stage or mark a stage task done without his word.
- Read `_planner/agents/README.md` first for the current agent list and statuses.
- The repo is public: no names, fees, student data, sheet ids, artifact or session links in any committed file.
- Jarvis data is written with the ArtifactData tool on the Jarvis artifact (link in `settings/main.jarvisUrl`); pin
  writes with if_version.
- Scheduled/run-now tasks: give him the filled text to paste and tell him which connectors to attach; he creates them.
- End by telling him plainly what stage the agent is at and what he does next.
